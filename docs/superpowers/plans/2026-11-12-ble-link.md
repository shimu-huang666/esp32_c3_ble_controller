# C3 最小 BLE 主控实施计划

> **For agentic workers:** 按用户已授权的方案在当前会话执行；不重复询问方案确认。使用完成前验证检查实际输出。

**Goal:** 从官方空白项目建立 C3 外围设备，收到四字节 PING 后通知回复四字节 PONG。

**Architecture:** 采用 ESP-IDF 自带 NimBLE，精简 bleprph 的广播和 GATT 服务注册流程。保留官方 mbuf 输入处理与通知机制，不重写蓝牙协议栈。

**Tech Stack:** ESP-IDF v6.1、ESP32-C3 Supermini、C、NimBLE、clang-format 21。

**Spec:** 当前对话中已确认的最小 BLE 双向通信需求；具体边界见下文。

## Global Constraints

- 与 S3 使用相同的服务 UUID、特征 UUID 和四字节 PING/PONG，不发送字符串结束符。
- 一对一、无配对认证；不接入麦克风、舵机或电源控制。
- 采用 Allman 格式；添加 Agent.md；代码、测试脚本、文档分别提交。
- 建立独立 Git 仓库，从空白 main 建立 codex/minimal-ble-link 功能分支。

## Review Focus

- S3 晚上电：C3 持续广播，允许其随后连接。
- 连接断开：C3 恢复广播。
- 广播长度：128 位 UUID 和设备名分别放入广播包与扫描响应，避免超过传统广播长度限制。
- 非四字节写入或内容不为 PING：返回 ATT 错误，不通知成功。
- 通知订阅：由 NimBLE 跟踪订阅，使用官方 ble_gatts_chr_updated 调度回复。
